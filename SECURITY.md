# Security Policy

## Reporting a security vulnerability

If you discover or suspect a security vulnerability in `exfat-resize`, please
report it privately using GitHub's
[private vulnerability reporting form](https://github.com/huven/exfat-resize/security/advisories/new).
Use this channel for any issue that may have security implications, including
when you are uncertain whether it is exploitable.

Please do not disclose security-related issues in a public GitHub issue, pull
request, or other public forum. Include enough information to help investigate
the issue, such as the affected version or commit, environment, potential
impact, steps to reproduce, and any relevant proof of concept.

The maintainer will review the report and coordinate next steps through the
private advisory. Please keep the report and related details private until
disclosure has been coordinated with the maintainer.

## Reporting other issues

For bugs, feature requests, and other issues without security implications,
use the [GitHub issue tracker](https://github.com/huven/exfat-resize/issues).
